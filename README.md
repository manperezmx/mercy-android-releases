# Mercy · instaladores Android

Repositorio de distribución de instaladores firmados. La aplicación web y sus servicios permanecen en el alojamiento de Mercy.

Cada versión conserva su APK, tamaño, SHA-256 y certificado de firma. Los archivos publicados no se sustituyen con bytes diferentes; las correcciones se publican con otra versión.

Paquete Android: `mx.mercy.preview`. Firma permanente SHA-256: `5b7833a44ac3770bae1b6eb18f134a87219be3d9337ba71f7b266adb607828da`.

Antes de instalar comprueba el SHA-256 del APK frente a SHA256SUMS.txt de su versión. La instalación desde el navegador requiere confirmación de Android.

La versión 0.17.0 se conserva como respaldo. Android normalmente no permite instalarla sobre una versión con código mayor; una restauración sin desinstalar requiere una nueva versión con código superior y la misma firma.

El detector de calidad facial y OCR local no equivalen a reconocimiento de identidad o prueba de vida. Esas capacidades no se anuncian como verificadas.

No contiene el código fuente de Mercy, claves de firma ni expedientes o datos de usuarios.
